Commitment b. The system creates/ modifies a new radiology request, generates a unique ID for
the request, and link it to the patient’s unique ID.
The system shall create a unique ID for a radiology request for every radiological
test or procedure. It should be able to link this unique ID with the patient's unique
identifier.
